## 二、画质影响排序（结合当前状态）

| 权重 | 项 | 当前状态 |
|---|---|---|
| ★★★★★ | 文本编码器量化 | nvfp4_awq 是当前**最大短板**，提示词遵循度受损 |
| ★★★★☆ | 分辨率 | 实际产出分辨率以后端注入为准，若仍 1344×768 可升 1080p（显存/时长上涨） |
| ★★★★☆ | 提示词/时间线分段 | 决定内容符合度，H3 玩法核心 |
| ★★★☆☆ | DiT 量化 | 已在 int8 甜区，非蒸馏上限需 bf16（61 GB，5090 放不下） |
| ★★☆☆☆ | VAE | fp16/fp32 已最优 |
| ★☆☆☆☆ | 采样器/调度 | euler/simple + shift 12/3 已配好 |
| — | 启动参数 | 只影响速度显存，不影响画质 |

## 三、升级建议（按性价比排序）

1. **换文本编码器**：`nvfp4_awq` → `int8_convrot`（服务器已有）。零成本、收益最大。注意显存（当前 GPU 常驻 22.5/32 GB，建议空闲时切）。
2. **确认/提升产出分辨率**：检查后端注入的分辨率；若 ≤1344×768，正式产出升 1080p 档。
3. **复核 8 步 turbo 实际出片质量**：若细节不足，唯一升级路径是非蒸馏 20 步路线，但依赖缺失的 `ref_lora_rank_256`，需先找回文件。
4. DiT、VAE、shift、采样器：**维持现状**，无需动。

> 改 UI 版后必须重跑 `scripts/build_comfyui_workflow_template.py` 重新生成 API 版才会生效。后端 `COMFYUI_MOCK` 默认 `true`，联调注意。timeline 段长须满足 5+17n 帧、≤3592 帧。
